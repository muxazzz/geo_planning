# Геопланирование

Локальное веб-приложение для распределения точек между менеджерами по алгоритму №3 из `notebook_geo_fin.ipynb`: KMeans с весами `n_visits`, балансировка нагрузки и построение ежедневных маршрутов.

## Запуск

Для запуска веб-приложения установите зависимости:

```bash
python3 -m pip install -r requirements.txt
```

```bash
python3 -m uvicorn app:app --host 127.0.0.1 --port 8000
```

После запуска откройте:

```text
http://127.0.0.1:8000/
```

## Формат входного файла

Поддерживаются `.csv`, `.xlsx` и `.xls`.

Обязательные колонки:

- `point_id` — идентификатор точки
- `lat` — широта
- `lon` — долгота
- `n_visits` — нужное количество посещений

Колонка `manager` используется для автоматического определения количества менеджеров. Для нового плана точки всё равно назначаются заново по алгоритму 3. Если в интерфейсе вручную указать количество менеджеров, оно переопределит значение из CSV.

## Результат

Приложение показывает:

- общую сводку по плану
- сводку по менеджерам
- сводку по кластерам
- карту точек и маршрутов
- таблицу маршрутов с фильтром по менеджеру
- выгрузку маршрутов в `routes.csv`
